# Skills

Each skill is law for one phase. Fill every `TODO` with the target language
after the crash course. Do not leave these as generic advice.

See `examples/catalog-compare-api/skills/` for a filled Go set.

| Skill | Used in |
| --- | --- |
| `idiomatic-code` | models, handlers |
| `testing` | failing-tests |
| `data-layer` | models |
| `http-handlers` | handlers |
| `middleware` | middleware |
| `documentation` | docs |
| `quality-gate` | gate |

The agent may draft a skill. A human accepts or rewrites it. Unreviewed
skills are vibe coding with extra markdown.
